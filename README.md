# 🤖 AI News Daily

> AI-curated daily news from top tech sources, with TLDR summaries generated by AI.

## 📰 Sources

- **TechCrunch AI** - Latest AI startup and industry news
- **The Verge AI** - Consumer AI and product launches
- **Wired AI** - Deep dives and analysis
- **VentureBeat AI** - Enterprise AI and research
- **Ars Technica** - Technical AI coverage

## 🤖 Features

- ✅ Top 5 stories from yesterday
- ✅ AI-generated 2-sentence TLDR
- ✅ Ranked by relevance
- ✅ Updated daily at 6:00 AM UTC

## 🔄 Automation

This repo is updated daily via cron job that:
1. Fetches RSS feeds
2. Filters yesterday's articles
3. Ranks by relevance
4. Generates TLDR summaries
5. Pushes to GitHub
